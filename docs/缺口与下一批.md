## 已知限制
- 本地 vLLM tools：需 `--enable-auto-tool-choice` + `--tool-call-parser hermes`；否则 runtime 对本轮自动降级为无 tools 补全（聊天仍有回复，但不调工具）
- ListMachines Phase 1：仅登记/列表/心跳；`host_ls`/`host_read` 为 stub；浏览器不登记为电脑；沙箱对用户透明，内部路由仍为 `/v1/sandbox*`
- 一期 JWT/密钥为开发默认值，生产必须改 `JWT_SECRET`；内部总线令牌默认 `INTERNAL_TOKEN=open-bot-dev-internal`
- LLM `api_key` 库内明文存储，仅 API 脱敏回传（未做 KMS 加密）
- 助手 `system_prompt` 与 runtime 内置 persona 拼接，需注意长度
- Skills：全局只读 + 用户可上传自定义（仅能删自己的）；name 须符合 Agent Skills（小写/数字/连字符）
- 记忆语义召回依赖 pgvector 与 `EMBEDDING_*`；扩展或嵌入服务不可用时自动降级关键词
- 从旧 `postgres:16` 升级到 pgvector 镜像时，开发库需删卷重建（`deploy_openbot_pg`）
- 压缩：主触发为 token 预算（可 per-connection `context_window`）；遗留消息/字符阈值仍仅 env；Web 设置页只读展示
- 协作总线：priority 可异步唤醒；默认不把 inbox 注入对话上下文；tools 默认关闭时仍可用 JWT HTTP + WS；工具路径代码已接内部 API（`OPENBOT_API_URL` / `INTERNAL_TOKEN`）
- MCP stdio 仅基础校验（命令白名单/危险字符/超时）；env 明文存库；按需启停不长驻
- A2A：默认可无鉴权（或设 `A2A_TOKEN`）；同步返回简化 Task；无 streaming / push / GetTask 全生命周期
- Routines：调度器仅 api 单进程；缺省 agent 为用户第一个助手 + 用户默认 LLM；cron 为服务器本地时区
- 桌面：未做代码签名/公证/自动更新；开发需本机 Rust + 先起 api/runtime
- 移动：未做应用商店上架/推送证书/原生插件大集合；真机需局域网 IP + `VITE_API_BASE`；`cap sync` 需 UTF-8 locale（Makefile 已设）
- Agent-bus WS：`CheckOrigin` 仅放行本机 localhost 开发 Origin；生产需收紧并改 token 传递方式
- 沙箱 Phase 1：容器内 root、默认 bridge 网络、无命令白名单；reset 会清空 workspace；Docker 不可用时 API 返回 503
- Langfuse：Phase-1 仅 Python agent-runtime；Go API / 多端 tracing 未接
