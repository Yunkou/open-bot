## 建议验证

1. `make dev-runtime` + `make dev-api` + `make dev-web`（可选 `ROUTINES_INPROCESS=0` + `make dev-worker`）。  
2. 设置 → 例行任务：建 cron（时区 Asia/Shanghai）→ 立即运行 → 侧栏出现「例行 · 名称」会话且含 `[routine]`。  
3. 创建入站 Hook；用 curl 打 Slack url_verification / 模拟 `event_callback`；或 GitHub `X-GitHub-Event: ping`。  
4. 聊天开启 tools：让助手 `create_routine`（可带 triggers）或 `defer_work`；确认先短确认、后台同会话出结果；发「别做了」可取消。  
5. `go test ./internal/db/ ./internal/httpserver/ ./internal/auth/`；`pytest tests/test_openbot_api_tools.py tests/test_deferral.py tests/test_dream_status.py`。
6. A2A：见 [a2a-adapter.md](./a2a-adapter.md) curl；用量页看 Runs；`make backfill-embeddings BACKFILL_ARGS='--dry-run'`。
