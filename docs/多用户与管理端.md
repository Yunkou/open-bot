# 多用户与管理端

> 目标：多人分权；身份用开源 IAM，业务后台自研薄封装。  
> 相关缺口见 [缺口与下一批.md](./缺口与下一批.md)；总览见 [技术方案.md](./技术方案.md)。

## 工程边界

| 工程 | 职责 | 本地 |
|------|------|------|
| **`deploy/compose.yaml`（profile `casdoor`）** + `deploy/casdoor/conf` | 仅 IAM（OIDC 登录、组织/用户目录）。**不**放业务管理 UI | `:8000`（DB `:5434`） |
| **`apps/web`** | 用户产品：聊天、设置。**不**引导进入管理端 | Vite `:5173` |
| **`apps/admin`** | 业务管理端：用户/Bot/追踪、成员、组织默认 LLM、用量、功能开关、审计日志；UI 为 **Ant Design ProComponents**（Vite + ProLayout 侧栏路由，非 Umi Max 全量脚手架） | Vite `:5174` |
| **`services/api`** | 统一 Go API：本地 JWT + org RBAC；`/v1/admin/*` 与聊天共用同一服务 | `:18080` |

明确不做：

- 把业务 Admin 塞进 Casdoor 或继续堆在 `apps/web` 的 `/admin` 路由里
- 为管理端再开第二个 Go 服务

```
浏览器(web :5173) ──┐
浏览器(admin :5174) ─┼→ Go API :18080（JWT / org RBAC）→ Python runtime
Casdoor :8000 ──────┘   （仅 OIDC 换发本地 JWT）
```

## 实现状态（2026-09-26）

| 阶段 | 状态 | 内容 |
|------|------|------|
| **P0** | ✅ | Casdoor Compose + OIDC 换发本地 JWT；本地密码登录仍可用 |
| **P1** | ✅ | `orgs` / `users.org_id`+`role` 迁移；默认 org 回填；管理 API 需 `org_admin+` |
| **P2** | ✅ | 独立 `apps/admin`：成员邀请与角色、组织默认 LLM、用量只读、功能开关；与 web 登录入口分离 |
| **P3** | ✅ MVP | `audit_logs` + 管理端只读表；组织默认 LLM 注入成员 run |

## 角色（一期）

| 角色 | 说明 |
|------|------|
| `platform_admin` | 平台级：跨租户只读/开关等（一期主要作最高角色） |
| `org_admin` | 租户管理员：成员、默认 LLM、本 org 功能开关、审计 |
| `member` | 普通成员 |

业务权限以 Go 侧 `users.role` 为准（可后续映射 Casdoor roles）。

## 数据

- 表 `orgs`（默认 slug=`default`）
- `users.org_id`（可空，迁移回填）、`users.role`、`users.email`、`users.casdoor_sub`
- `org_settings`（组织默认 LLM + `feature_flags_json`）
- `org_invites`（待注册邀请）
- `audit_logs`（org 级审计：actor、action、target、meta_json）

## LLM 选用优先级（聊天 / run）

发消息时若未指定 `llm_connection_id`：

1. **用户个人覆盖**：`llm_connections` 中该用户的 `is_default`，若无则取该用户最早一条连接  
2. **组织默认**：`org_settings` 中已配置的 LLM（base_url / model / api_key 任一非空即视为已配置）  
3. **无可用连接**：不注入 `llm` payload（runtime 可走 echo / 环境变量兜底）

显式 `llm_connection_id` 始终优先于以上规则。

## 审计动作（P3 MVP）

| action | 触发 |
|--------|------|
| `member.invite` | 创建待接受邀请 |
| `member.invite_join` | 邀请时目标用户已存在并立即入组 |
| `member.role_change` | 修改成员角色 |
| `user.create` / `user.update` / `user.delete` | 管理端用户 CRUD |
| `bot.create` / `bot.update` / `bot.delete` | 管理端 Bot CRUD |
| `org.llm_update` | 保存组织默认 LLM |
| `org.feature_flags_update` | 保存功能开关 JSON |
| `auth.login` | 用户端密码登录 |
| `auth.admin_login` | 管理端密码登录 |
| `auth.oidc_login` | 用户端 Casdoor/OIDC 换发成功 |
| `auth.admin_oidc_login` | 管理端 OIDC 换发成功 |

`GET /v1/admin/audit-logs`（`org_admin+`）只读列表。


## 角色与产品边界（重要）

| 谁 | 用什么 | 怎么得到角色 |
|----|--------|--------------|
| **终端用户（聊天）** | 只开 `apps/web` `:5173`；`POST /v1/auth/register` / `/v1/auth/login` | 新注册**永远**是 `member`；邀请默认也是 `member` |
| **运营（业务管理端）** | 只开 `apps/admin` `:5174`；`POST /v1/admin/auth/login` | `BOOTSTRAP_ADMIN_*` 引导出 `platform_admin`，或邀请/授予 `org_admin` / `platform_admin` |
| **Casdoor IAM** | `:8000` | **不是**业务管理端；只做 OIDC 身份 |

同一 `users` 表，但**管理端不是普通用户可以用的**：`member` 调管理端登录会 **403**「此账号无管理端权限」。

邀请约定：

- `member` = 终端用户（聊天）
- `org_admin` / `platform_admin` = **管理员账号**（可登 `:5174`）
- 管理端邀请表单默认角色为 `member`

## 怎么进入管理端登录

### 终端用户

- 只启动并打开用户端：`make dev-web` → **http://127.0.0.1:5173**
- **永远不要**进管理端（`:5174`）。用户端侧栏**不再**提供「管理端」入口。

### 运营

1. **准备管理员账号（二选一）**
   - **推荐（新安装）**：在 `.env` 设置：
     ```bash
     BOOTSTRAP_ADMIN_USERNAME=ops-admin
     BOOTSTRAP_ADMIN_PASSWORD=change-me
     # 可选：BOOTSTRAP_ADMIN_EMAIL=ops@example.com
     ```
     启动 API 时：若库中尚无任何 `platform_admin`，则创建（或提升已存在同名用户为）默认组织的 `platform_admin`。
   - **已有环境**：库里已有 `org_admin` / `platform_admin`（历史首用户若已是 `platform_admin` 会保留，不再对新注册自动提权）。
2. 起 API 与管理端：
   ```bash
   make dev-api
   make dev-admin
   ```
3. 浏览器**直接**打开 **http://127.0.0.1:5174**（标题「open-bot 管理端」）。
4. 用**管理员账号**走管理端登录（`POST /v1/admin/auth/login`）。`member` 会被拒绝并提示去用户端。
5. 可选 OIDC：`POST /v1/admin/auth/oidc/exchange`（或带 `X-Client: admin` / `audience=admin`）；同样校验管理员角色。

**Casdoor `:8000` 仍是 IAM，不是业务管理端。** 不要用 Casdoor 自带的 `built-in/admin` / `123` 登 open-bot 管理端。

### 新安装 vs 已有库

| 场景 | 行为 |
|------|------|
| 新注册 `/v1/auth/register` | 一律 `member` |
| migrate 回填 | 只补 `org_id` / 空 role→`member`；**不再**把「第一个用户」提成 `platform_admin` |
| 已有 `platform_admin` 行 | **保留不动** |
| `BOOTSTRAP_ADMIN_*` | 仅当库中还没有任何 `platform_admin` 时生效 |

## 登录流

1. **用户端（聊天）**：`POST /v1/auth/login` / `register`；OIDC → `POST /v1/auth/oidc/exchange`
2. **管理端（运营）**：`POST /v1/admin/auth/login`；OIDC → `POST /v1/admin/auth/oidc/exchange`（非管理员 403）

## 管理端 UI（`apps/admin`）

- 构建：仍用 **Vite**（`make dev-admin` → `:5174`），**不**引入 Umi Max / Ant Design Pro 完整 monorepo。
- UI：`antd` + `@ant-design/pro-components`（ProLayout 侧栏、PageContainer、ProTable、ProForm）+ `react-router-dom`；`ConfigProvider` 使用 `zhCN`。
- 路由：登录页；登录后侧栏 — 用户管理 `/users`、Bot 管理 `/bots`、调用追踪 `/traces`、成员与角色 `/members`、默认模型 `/llm`、用量 `/usage`、功能开关 `/flags`、审计日志 `/audit`。
- API 客户端仍为 `apps/admin/src/api.ts`（`/v1/admin/*`）；与用户端 `apps/web` 入口分离。

## 用户 / Bot / Trace API（节选）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET/POST | `/v1/admin/users` | 列出 / 创建本组织用户（排除 `__a2a__`） |
| PATCH/DELETE | `/v1/admin/users/{id}` | 更新邮箱/角色/密码；删除（禁删自己、唯一 `platform_admin`、系统用户）。删除走 FK `ON DELETE CASCADE` |
| GET/POST | `/v1/admin/bots` | 组织内助手列表 / 为组织成员创建 |
| PATCH/DELETE | `/v1/admin/bots/{id}` | 更新 / 删除非内置 Bot（校验所有者在本 org） |
| GET | `/v1/admin/traces` · `/traces/{id}` · `/traces/status` | 代理 Langfuse v4 `GET /api/public/v2/observations`（`isRootObservation`）；未配置返回 `{enabled:false}` |

组织范围：`org_admin` / `platform_admin` 均按调用者 `users.org_id` 作用域操作（一期不做跨租户用户目录）。

## 管理菜单（MVP）

| 做 | 不做 |
|----|------|
| 用户管理 CRUD（含邀请）`/users` | 完整计费 |
| Bot 管理（组织内助手）`/bots` | 连接器市场 |
| 调用追踪（Langfuse 代理）`/traces` | 自建全量可观测栈 |
| 成员邀请与角色 `/members` | 跨租户 platform 控制台 UI |
| 租户默认 LLM（注入成员 run） | |
| 用量只读（消息/会话/助手计数） | 用量按 runs 细粒度 |
| 功能开关 JSON | |
| 审计日志只读 | |

## 本地怎么跑

见 [本地启动.md](./本地启动.md)#casdoor多用户与管理端：

```bash
make compose-casdoor          # IAM UI :8000；DB :5434
# Casdoor Applications → app-built-in：填 Client ID/Secret + Redirect URI（web :5173）
# 写入 .env 的 CASDOOR_* 后重启 make dev-api

make dev-api                  # :18080
make dev-web                  # 用户端 :5173
make dev-admin                # 管理端 :5174
```

运营直接打开 `:5174` 使用管理端登录；勿从聊天端「随便登进管理端」。

## 明确不建议

- 双用户表长期并存（Casdoor 与本地 users 各一套、互不同步）——当前为 **Casdoor 身份 → 本地 users 一行**（`casdoor_sub`）。
- Fork 全栈中后台脚手架替换现有 API 面。
- 在 Casdoor 内做业务后台，或把 admin 继续嵌进 `apps/web`。
