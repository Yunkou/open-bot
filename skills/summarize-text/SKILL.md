# Summarize Text

## When to use
- User pastes a long article, transcript, or notes
- User asks for TL;DR / 摘要 / 要点

## Instructions
1. Identify the main topic and audience.
2. Prefer 3–7 bullet points for structured content; use one short paragraph for narrative.
3. Preserve numbers, names, and decisions; drop filler.
4. Reply in the same language as the user input unless asked otherwise.
5. If the source is ambiguous, state assumptions briefly.

## Output template
```
**摘要**
- …
- …

**可执行下一步**（可选）
- …
```
