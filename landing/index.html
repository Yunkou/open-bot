多模型接入

每用户独立配置多条 LLM 连接，支持 OpenAI 兼容接口，随时切换、设默认。

自定义助手

创建多个助手人设，独立 system prompt，按需切换对话风格与专业领域。

🔧

MCP 工具集成

记忆语义召回
